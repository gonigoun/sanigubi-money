## 처음 한 번만: Firebase 준비 (약 10분)

Firebase는 Google이 만든 무료 저장소예요. 정산 내용과 영수증 사진이 여기에 저장돼요. 무료 요금제(Spark)로 충분해요.

### 1. 프로젝트 만들기
1. https://console.firebase.google.com 에 gonigoun@gmail.com 으로 들어가요.
2. **프로젝트 만들기**(또는 프로젝트 추가)를 누르고 이름을 `sanigubi-money` 로 적어요.
3. Google 애널리틱스는 **사용 안 함**으로 두고 만들어요.

### 2. Google 로그인 켜기
1. 왼쪽 메뉴 **빌드 → Authentication → 시작하기**를 눌러요.
2. **로그인 방법** 탭에서 **Google**을 고르고 **사용 설정**을 켠 뒤, 지원 이메일로 gonigoun@gmail.com 을 고르고 저장해요.
3. **설정** 탭 → **승인된 도메인** → **도메인 추가** → `gonigoun.github.io` 를 넣어요.

### 3. 저장소(Firestore) 만들기
1. 왼쪽 메뉴 **빌드 → Firestore Database → 데이터베이스 만들기**를 눌러요.
2. 위치는 **asia-northeast3 (서울)**, 모드는 **프로덕션 모드**로 골라요.
3. 만들어지면 **규칙** 탭을 열고, 이 저장소의 `firestore.rules` 내용을 통째로 붙여 넣은 뒤 **게시**를 눌러요.
   - 이 규칙 덕분에 **누구나 읽기만** 할 수 있고, **gonigoun@gmail.com 만 고칠 수** 있어요.

### 4. 웹 앱 설정값 받기
1. 왼쪽 위 톱니바퀴 → **프로젝트 설정** → 아래쪽 **내 앱**에서 웹 아이콘(`</>`)을 눌러요.
2. 앱 닉네임은 `sanigubi-money`, "Firebase 호스팅"은 체크하지 않고 **앱 등록**을 눌러요.
3. 화면에 나오는 `firebaseConfig = { apiKey: ..., authDomain: ..., projectId: ..., ... }` 부분을 복사해서 Claude에게 보내 주세요. (공개돼도 괜찮은 값이에요.)
4. Claude가 `firebase-config.js` 에 넣어 올리면 끝이에요.

### 5. 처음 자료 넣기
1. 사이트 맨 아래 **관리자** → Google로 로그인
2. **처음 자료(2026년 1~10월) 넣기** 버튼을 한 번 눌러요. (자료가 하나도 없을 때만 보여요)

## 매달 하는 일

### 방법 A. 엑셀로 한 번에
1. 관리 화면 → **엑셀로 한 번에 불러오기**에서 정산 엑셀 파일을 골라요.
2. 시트 목록에서 이번 달을 체크하고 **선택한 달 저장하기**를 눌러요.
   - 시트 B2 칸 제목이 `2026년 11월 OO산 정산 내역` 모양이어야 찾아요.
   - B열 항목, C열 수입(글자를 쓰면 현물 찬조로 들어가요), D열 지출, F열 비고, E5 이월을 읽어요.
   - 이미 있는 달을 다시 불러오면 정산 표만 바뀌고, 사진과 영수증 설명은 그대로예요.

### 방법 B. 직접 입력
1. 관리 화면 → **+ 새 달 직접 입력**
2. 지난달 잔액이 전월 이월에 자동으로 들어가요. 항목과 금액을 적고 **저장하기**.

### 영수증 사진 올리기
1. 월 목록에서 그 달의 **편집** → 아래 **사진 고르기**
2. 여러 장을 한꺼번에 골라도 돼요. 크기는 자동으로 줄여서 저장해요.
3. 사진 아래 칸에 설명(예: `하산식 952,000원`)을 적으면 바로 저장돼요. ◀ ▶ 로 순서를 바꿀 수 있어요.
4. 금액 맞추기 설명이 필요하면 **영수증 설명** 칸에 적고 저장하세요. 사진 아래에 보여요.
